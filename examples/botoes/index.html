O Bootstrap 5 oferece diferentes estilos de botões:


As classes de botão podem ser usadas em elementos a, button, or input

Contorno de botão

O Bootstrap 5 também oferece oito botões com contorno/borda.

Tamanhos de botões

Botões de nivel de bloco

Um botão de bloco ocupa toda a largura do seu elemento pai.

No Bootstrap 5, você pode criar um botão de largura total colocando-o dentro de um contêiner com a classe .d-grid.

A classe .d-grid cria um contêiner em forma de grade que permite que o botão se estenda por toda a largura.

Gap

Se você tiver muitos botões de nível de bloco, poderá controlar o espaço entre eles com a classe .gap-*

Botões Ativos/Desativados

Um botão pode ser configurado para um estado ativo (parecer pressionado) ou desativado (não clicável)

A classe .active faz com que um botão pareça pressionado, e o atributo disabled faz com que um botão não possa ser clicado. Observe que os elementos a não suportam o atributo disabled e, portanto, devem usar a classe .disabled para que pareçam visualmente desativados.
