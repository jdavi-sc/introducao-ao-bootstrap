NavBar

Com o Bootstrap, uma barra de navegação pode se expandir ou se recolher, dependendo do tamanho da tela.

Uma barra de navegação padrão é criada com a classe .navbar, seguida por uma classe de recolhimento responsiva: .navbar-expand-xxl|xl|lg|md|sm (empilha a barra de navegação verticalmente em telas xxlarge, extra large, large, medium ou small).

Remova a classe .navbar-expand-* para criar uma barra de navegação que será sempre vertical.

Marca / logotipo

A classe .navbar-brand é usada para destacar a marca/logotipo/nome do projeto da sua página

Logo

Ao usar a classe .navbar-brand com imagens, o Bootstrap 5 estilizará automaticamente a imagem para que ela se ajuste verticalmente à barra de navegação.

Barra de navegação recolhível

Para criar uma barra de navegação recolhível, use um botão com class="navbar-toggler", data-bs-toggle="collapse" and data-bs-target="#thetarget"

Em seguida, envolva o conteúdo da barra de navegação (links, etc.) dentro de um elemento div com class="collapse navbar-collapse" seguido por um id que corresponda ao do data-bs-target do botao "thetarget
